# Chimera Mod

Adds unique chimera creatures to Minecraft, created via ritual tables.

## Features

- Adds chimera creatures to the game
- Allows creation of chimeras by dropping mobs on a ritual table

## Requirements

- Minecraft 1.18.2
- Forge 40.1.0 or later

## Installation

1. Download the latest version of the mod from the [releases page](https://github.com/EnderDevelopment/chimera-mod/releases).
2. Place the downloaded JAR file in your Minecraft mods folder.
3. Launch Minecraft and select the Forge profile.

## Usage

1. Craft a ritual table using the in-game crafting system.
2. Drop mob items on the ritual table to create a chimera.
3. Spawn the chimera in the world and interact with it.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the source code.
